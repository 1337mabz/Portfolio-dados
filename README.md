# Portfólio de Dados

Portfólio de análise de dados, automação (n8n) e agentes de IA.

## Estrutura

```
.
├── data/        # dados locais (não versionado)
├── notebooks/   # análises em Jupyter
└── sql/         # consultas e modelos SQL
```

## Stack

- **Python** — pandas, DuckDB, SQLAlchemy
- **SQL** — DuckDB, PostgreSQL
- **Automação** — n8n
- **IA** — agentes e LLMs

## Como rodar

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
